# GUIDE DE DIRECTION ARTISTIQUE - PORTFOLIO 2026
**Vision :** L'Architecte Digital // Editorial Minimalist Tech
**Cible :** Clients Premium, Agences Awwwards, Recruteurs Tech

---

## 1. L'ESSENCE DU DESIGN (MOOD)
L'interface doit respirer. Elle n'est pas là pour décorer, mais pour structurer l'information avec une élégance mathématique. On cherche l'équilibre entre la chaleur du design éditorial (magazines de mode) et la précision de l'ingénierie logicielle.

* **Mots-clés :** Rigueur, Espace, Typographie Cinétique, Matériaux Bruts.
* **Inspiration :** *Inspi.jpg* (Structure grille, lignes fines) & *Inspi2.jpg* (Typographie Playfair, Mockups 3D).

---

## 2. SYSTÈME TYPOGRAPHIQUE
Le contraste est la clé. On joue sur l'opposition entre le classique (Serif) et le moderne (Sans/Grotesque).

### A. Display & Titres (L'Émotion)
* **Font :** **Playfair Display**
* **Usage :** Gros titres (H1, H2), Citations, Mots-clés "Hero".
* **Style :** Utiliser l'**Italique** pour mettre l'emphase sur 1 mot dans une phrase.
    * *Exemple :* "Digital products that create *emotion*."

### B. Corps de Texte & UI (La Fonction)
* **Font :** **Outfit** (Alternative: Manrope)
* **Usage :** Paragraphes, Boutons, Menus, Labels.
* **Style :** Graisses variées. `Light` pour le texte courant, `Medium` pour les boutons. Interlignage large (150%).

### C. La "Touche Code" (Le Détail)
* **Font :** **JetBrains Mono** ou **Space Mono**
* **Usage :** Numérotation (01, 02), Tags techniques (React, GSAP), Crédits en footer.
* **Taille :** Très petit (10px - 12px), souvent en majuscules.

---

## 3. PALETTE CHROMATIQUE
Une base monochrome stricte pour laisser les images "popper".

| Usage | Couleur | Hex | Description |
| :--- | :--- | :--- | :--- |
| **Fond** | **Off-White** | `#F4F4F0` | Papier d'art, doux pour les yeux. Pas de blanc #FFF pur. |
| **Encre** | **Charcoal** | `#1A1A1A` | Texte principal, contraste fort mais pas agressif. |
| **Grille** | **Mist** | `#E0E0E0` | Lignes de séparation, bordures fines (1px). |
| **Accent** | **Acid Lime** | `#CCF077` | Couleur vibrante pour l'interaction (Hover, CTA, Curseurs). |
| **Sec.** | **Deep Slate** | `#2C3E50` | Pour les éléments "tech" ou les fonds sombres alternatifs. |

---

## 4. UI KIT & COMPOSANTS CLÉS

### La Grille (The Grid)
* **Visible :** Les lignes de la grille doivent être visibles (fines bordures grises).
* **Layout :** Bento Grid (Blocs rectangulaires assemblés).
* **Marges :** Généreuses. Le contenu ne doit jamais toucher les bords de l'écran (Padding 40px min).

### Les Images & Mockups
* **Rendu :** Photoréaliste, Studio 3D.
* **Matériaux :** Verre dépoli (Frosted glass), Béton brut, Métal brossé, Végétal minimaliste.
* **Formes :** Rectangles aux coins légèrement arrondis (Radius 8px ou 0px pour un look brutaliste).

### Micro-Interactions (Notes pour la maquette)
* Prévoir des états "Hover" très visuels (ex: l'image change ou s'agrandit au survol).
* Boutons : "Pill shape" (arrondis) ou soulignés très finement.
